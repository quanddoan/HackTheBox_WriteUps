# HackTheBox Writeups

Welcome to my collection of Hack The Box writeups.

This repository documents my investigations and solutions to various HTB, mostly Sherlocks, with a focus on digital forensics, incident response, threat hunting, and analyzing real-world attack artifacts.

Each writeup covers the investigation process, including the evidence examined, tools and techniques used, relevant findings, and the reasoning behind each answer.

## What you'll find:
- Digital forensics investigations
- Windows and Linux artifact analysis
- Log and event analysis
- Network and browser forensics
- Threat hunting and incident response
